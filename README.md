# 知行 · 行测考场思维错题本

个人使用、手机优先的行测 PWA。题库和图片保存在本机 IndexedDB；静态部署到 GitHub Pages，无后端服务。开发版本 0.1。

## 运行

需要 Node.js 22 或以上及 pnpm 11。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
pnpm preview
```

`dev` 用于开发；离线和更新测试需执行 build 后用 preview。默认只绑定本机地址。手机请使用部署后的 HTTPS 网址，不要把电脑 localhost 地址复制到手机。

## GitHub Pages 部署

1. 在 GitHub 建立一个用于此应用的仓库。将 **本目录 xingce 内的源文件** 上传到仓库根目录；不要上传上级 sources、个人照片或备份。保留 `.github/workflows/pages.yml`、`pnpm-lock.yaml` 和 `pnpm-workspace.yaml`。
2. 默认分支用 `main`。仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. 推送后工作流先测试、构建，再仅发布 `dist`。工作流不会请求 AI，也不需要任何模型密钥。
4. 在 iPhone Safari 打开 Pages 网址，分享 → 添加到主屏幕。

使用相对资源路径及 hash 路由，支持 `用户名.github.io/仓库名/` 子路径。首次打开需联网缓存全部页面和公式字体。应用更新不会删除 IndexedDB；新版本就绪后提示保存并更新。

**目前没有连接你的 GitHub 账户或发布公开网址。** 源码和发布配置已准备；账户连接/创建远程仓库需要后续完成。

## 首次设置

“我的”中填入 API Key，地址默认为 `https://www.leaderai.top/v1`，当前平台模型 ID 为 `g6a-promotion4`（用户选择的 Astra 通道）。模型真实性、能力与计费以平台实际服务为准。

密钥默认只保留在当前页面会话内，刷新后可能需要重填；主动选择“在此设备记住”才持久保存。持久保存不是密钥保险箱，同源脚本可以访问。密钥按 API 地址绑定，改地址不会把旧密钥自动发到新地址。

连接与图片测试会发送随机数字图片，可能产生费用，需点击确认。它只验证当次联网、读图与 JSON 返回，不代表行测准确率。

此前无密钥预检发现平台未放行测试用外部来源。用户决定先开发，**这不代表跨域已解决**。发生网络/CORS 错误时本应用保留草稿、不自动重试、不使用代理。最终 Pages 来源仍需通过测试。

平台已看到的输入价是 725 积分/百万 token 起，输出价未确认，故应用不默认启用费用估算。输入输出价格、单位、倍率和预算可修改；若填折后实际价，请设倍率 1，避免重复折扣。未知用量不会显示为免费。

## 使用流程

1. 拍照、选多张图片或手动输入文字。选图后立即存草稿；同图哈希匹配会提示重复。
2. 点击识别。多图可排序；自动拆题可勾选“一图多题”。每题边界可通过百分比控件修正并实时预览，也可复制图片区域拆题。
3. 对照原图修改题干、单位、选项、材料、否定词和模糊条件。参考答案、机构解析与模型结论分开保存。**裁剪掉解题图片与材料中的答案区域**，再勾选核对完成。
4. 点击生成考场解析。这是第二次显式模型调用；求解文本不传参考答案，图形题仍传必要图像。只有用户确认过的无答案图片才传入求解阶段。
5. 检查推荐方法、第一动作、停止条件和取舍。未解决疑问、参考答案冲突或数值验证不符进入待核对，不生成正式知识卡片。
6. 复习先隐藏答案，作答后反馈并选择不会/吃力/掌握。刚看过解析、猜对和同日反复答对不直接计为稳定掌握。初始间隔是可调整逻辑的 1/3/7/14/30 天，不保证固定周期有效。

已保存解析、查看知识卡片、练习和提醒安排均不发模型请求。额外分析或重新识别必须明确操作。切后台、锁屏、关闭网页可能中断，恢复时约 60 秒过期保护后标记中断，不自动重发；服务端可能已经收费。

知识卡片保留每条来源，来源文字不同或题目修改时标记待核对。只向 AI 发送相关分类及最多 4 张候选卡片。可合并、按关联题拆分，或在题目中纠正分类。共享材料修改后关联小题与卡片都需重新核对。

## 备份与清理

导出为 ZIP：包含版本清单、逐文件 SHA-256、图片、题目、共享材料、分析历史、知识来源、调用用量和复习记录。**不含 API Key 或 API 连接设置**。可下载到 iPhone“文件”并手动选择 iCloud Drive；不是自动同步。

导入先校验版本、文件完整性、大小、重复 ID 和关系，再在单次数据库事务中写入。已有相同 ID 时整次取消，不静默覆盖；完整恢复建议在空题库设备或浏览器进行。压缩备份上限 100 MB，解压总量上限 300 MB。

稳定掌握满 90 天（可改）且未收藏的题可列为清理候选；图形推理、资料图表、共享材料和仍被保护题引用的图片不清理。只清理合格候选的冗余原图，保留 2200px 范围清晰副本、文字和记录。自动清理默认关闭，仅启用后在打开应用时执行。

## 验证与边界

详见 [验证记录](docs/验证记录.md)。内置两道题为自编演示，不是假装 AI 生成的真实样本。

- 尚无真实 API 凭据测试，不能报告模型识别/解题准确率。
- 实体 iPhone Safari、主屏幕模式和最终 Pages 域名需部署后验收；桌面手机尺寸预览不等同真机。
- 不做关闭网页后的准时推送。可在 iPhone“提醒事项”设置每日提醒。
- 完整试卷训练尚未加入；错题练习记录不代表整场考试水平。
- 对多图、拆题、图形识别和分类质量的自动化验证仅使用模拟返回；实际结果取决于平台视觉能力和人工核对。
- 受控验证支持有界数值表达式，禁止执行模型代码。数值核对不等于证明整题正确。

## 文件组织

`src/domain.ts` 数据与返回 schema；`db.ts` 本地事务；`workflow.ts` 识别/求解；`api.ts` 直连/密钥/用量；`images.ts` 图片；`core.ts` 算式与复习；`backup.ts` 完整备份；`storage.ts` 清理；`pages/` 手机界面。`scripts/build-sw.mjs` 构建离线缓存，`tests/` 保存回归测试。
