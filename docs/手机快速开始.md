# 手机快速开始

1. 在 iPhone Safari 打开发布后的网址，点击分享 → 添加到主屏幕。
2. “我的”中填写 API Key，核对地址、模型 ID 与价格。模型暂按你选择的 Astra 通道配置，所有项目可改。
3. 先点一次“连接与图片测试”。该操作可能产生平台费用；若失败，页面会说明原因，题库不会被清空。
4. 在“今天”拍照或选截图。先保存草稿，再识别。多图可以排序，一图多题可拆分。
5. 对照原图核对文字和图片边界，把答案与机构解析移出解题图片，然后点“核对完成”。
6. 明确点击“生成考场解析”。参考答案与模型结论分开；冲突或条件不完整时，保持待核对。
7. 复习先作答再看解析。错题、做慢、蒙对或来不及做都可以留下。
8. 每周到“我的”导出完整题库，生成后再点“保存备份文件”，保存到“文件”或手动选择 iCloud Drive。

本机电脑预览地址只能用于这台电脑；手机使用需要最终 GitHub Pages HTTPS 网址。第一次打开请保持联网完成页面缓存。密钥不在备份里，换设备需要重新填写。
