# 手机快速开始

1. 在 iPhone Safari 打开 [知行错题本](https://dpclaude.github.io/xingce-field-notes/)，点击分享 → 添加到主屏幕。
2. “我的”中填写小米 MiMo API Key。地址 `https://api.xiaomimimo.com/v1`，模型 `mimo-v2.6-pro`；所有项目可改。需要重新打开仍可用时勾选“在此设备记住”再保存。
3. 先点一次“连接与图片测试”。该操作可能产生平台费用；若失败，页面会说明原因，题库不会被清空。
4. 在“今天”拍照或选截图，草稿自动保存在本机。
5. 点一次“自动识别并解析”，系统负责识别、核对、拆题、求解与知识归类。请保持页面打开。
6. 直接查看考场解析。只有确实看不清、缺图或答案冲突时才提示具体问题；可在“补充或更正”中补图。无需逐项勾选核对，已有结果不会重复收费分析。
7. 复习先作答再看解析。错题、做慢、蒙对或来不及做都可以留下。
8. 每周到“我的”导出完整题库，生成后再点“保存备份文件”，保存到“文件”或手动选择 iCloud Drive。

本机电脑预览地址只能用于这台电脑；手机使用需要最终 GitHub Pages HTTPS 网址。第一次打开请保持联网完成页面缓存。密钥不在备份里，换设备需要重新填写。
