# 第一版验证记录

- TypeScript 严格类型检查通过；Vite 生产构建通过；22 项自动测试通过。
- 自动测试覆盖有界算式、参考答案冲突、缺失条件、复习间隔、近期暴露与跨日实测用时、JSON 格式错误、请求互斥、无自动重试、陈旧页面版本冲突、孤立任务恢复、知识卡片防止同分类误合并、多题边界与共享材料、图片/复习记录备份恢复、凭据排除、篡改拒绝、大包导出限制。
- Windows Edge 浏览器实际操作：空库、加载明确标注的自编演示、手动录题、刷新后数据保留、无密钥的清楚错误提示、多图上传和排序、裁剪修改后保存、隐藏答案复习、提交后解析展示、近期看过解析提示。

- 确认本机预览服务停止后刷新，首页与独立作答仍能打开。修复了预缓存请求与跨来源属性模块请求在 Vary: Origin 下匹配失败的问题。没有修改系统网络设置。
- 390×844 手机尺寸浏览器排版检查。此结果不是实体 iPhone 验收。
- 新上下文代码复查，已修复编辑覆盖、任务锁恢复、复习暴露、备份大小不对称、识别过程中编辑等问题。

## 未执行或有限制

- 未输入真实 API Key，没有实测 Astra 的图片识别、返回格式或行测解题准确率。模拟响应测试只能验证应用行为。
- 先前中转预检发现测试外部来源没有跨域放行；用户决定按可用假设开发。最终 Pages 来源能否直连仍需平台实测。本应用没有代理和付费后台。
- 未在实体 iPhone Safari / 主屏幕模式验收，尚未验证真机拍照、锁屏、分享保存与系统回收。
- 无真实历年考题样本评测。内置两道是有可人工复核答案的自编示例，不能据此给出模型准确率或分类准确率。
- 程序验证目前支持有界数值表达式，尚未提供通用有限穷举验证器。
- 知识标题优先复用候选卡片，目录稳定且支持手动合并拆分；语义同义规则的自动合并质量仍需实际题目验证。
- 第一版备份是单包 ZIP，压缩100MB、解压300MB、单文件60MB上限；导出也执行相同保护。超大题库分卷尚未实现。
- 首次生产构建约 928KB JavaScript（压缩约287KB），含公式与本地数据依赖；构建有单包大小提示，后续可按使用数据拆分优化。
- v1 数据库的刷新与应用缓存更新保留数据已检查；尚无未来版本数据库结构迁移可供验收。
- 完整试卷训练、关闭网页后的定时系统推送、多设备自动同步均未实现。
